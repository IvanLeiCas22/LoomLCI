# LoomLCI

Segundo cerebro del proyecto LoomLCI.

## Estado

Arquitectura v0.1 reconciliada y baseline cerrada. Milestone 1 (Process), Milestone 2 (Filesystem), C1 (Native Process + Job Objects), C2 (ConPTY), D0 (resource lifetime/expiry + `process_release`), Python Runtime E1 y **Agent Support F1** están implementados y validados. F1.3 quedó confirmado por el benchmark real-world final: **4/4 positivos claros, 3/3 controles simples y escalada 8A sin plan -> 8B con plan** usando la skill del plugin 0.2.1. [[Deployment portable]] está **implementado y validado end-to-end en dos PCs Windows x64**: instalación Release self-contained, launcher Start/Stop/Status/Setup, acceso directo, cutover/rollback, migración entre escritorio y notebook y smoke real desde ChatGPT en ambas máquinas. Quedan sólo mejoras de UX no bloqueantes. **Visual Files G1 tiene investigación/diseño v0.1 cerrados y está listo para implementación desde G1.0; Computer continúa después como H1.**
