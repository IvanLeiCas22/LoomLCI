# LoomLCI

Runtime local para que agentes como ChatGPT trabajen sobre Windows mediante capacidades estructuradas, procesos y Python. La conexión productiva de ChatGPT utiliza una aplicación MCP y Secure MCP Tunnel.

**Documentación vigente:** [Abrir inicio](docs/00-Inicio/Inicio.md) · [Estado operativo](docs/01-Estado-actual/Estado%20del%20sistema.md) · [Arquitectura](docs/02-Arquitectura/Arquitectura%20actual.md) · [Desarrollo](docs/05-Desarrollo/Guia%20de%20desarrollo.md).

La raíz del repositorio mantiene `src/`, `tests/`, `scripts/`, `plugin/` y `docs/`. El directorio `docs/90-Historial/` preserva investigaciones y registros anteriores **como evidencia histórica**, no como instrucciones operativas actuales.

> Para editar el proyecto: revisar el código actual, investigar y proponer antes de aplicar cambios; implementar después de la aprobación del usuario. No ejecutar actualizaciones destructivas desde el propio Host que se está deteniendo.
